## Open Source vs Software Libre

Aunque muchas veces van de la mano y tienen muchas cosas en común, el movimiento del **Software Libre** y el movimiento **Open Source** tienen filosofías y enfoques muy distintos, pues mientras uno tiene un enfoque **ético y social**, otro tiene un enfoque **práctico y empresarial**. No son excluyentes y mucho software encaja en ambos, pero es importante entender la diferencia.

### Software Libre

El movimiento de software libre fue impulsado por _Richard Stallman_ y la _Free Software Foundation_ en los años 80.

Su enfoque es **ético y social**: _el usuario debe tener libertad sobre el software que usa._

Las “4 libertades” son:

1. Usar el programa para cualquier propósito.
2. Estudiar cómo funciona.
3. Modificarlo.
4. Compartir copias y mejoras.

Aquí “_free_” significa libertad, no precio.

Para este movimiento, software privativo es un problema porque limita la autonomía del usuario.

### Open Source

El término “open source” apareció después, en 1998, impulsado por organizaciones como la Open Source Initiative.

Su enfoque es más **práctico y empresarial**:

- mejor calidad de software,
- colaboración,
- auditoría pública,
- innovación más rápida,
- evitar vendor lock-in.

El open source evita el discurso ético fuerte del software libre porque **buscaba ser más aceptable para empresas**.

Hoy prácticamente toda la industria tecnológica depende de open source:

**Google**, **Microsoft**, **Amazon**, **Meta**

usan y liberan **enormes cantidades** de software open source.

Tecnologías modernas **dependen** fuertemente de ello:

- Kubernetes
- Docker
- NGINX
- PostgreSQL
- React

El open source **ya es infraestructura crítica global**, y esta comunidad **domina** completamente en:
- cloud,
- DevOps,
- backend,
- infraestructura,
- desarrollo moderno.

Pues en estas areas importa:
- productividad,
- estándares,
- ecosistemas,
- interoperabilidad.

---

De hecho _Richard Stallman_ (principal referente del movimiento del Software libre) habló de esta diferencia:

> _Los términos «software libre» y «código abierto» se refieren prácticamente al mismo conjunto de programas. Sin embargo, transmiten mensajes muy diferentes sobre esos programas, basados en valores distintos. El movimiento del software libre aboga por la libertad de los usuarios de la informática; es un movimiento en favor de la libertad y la justicia. Por el contrario, la idea del código abierto valora principalmente las ventajas prácticas y no defiende principios. Por eso no estamos de acuerdo con el código abierto y no utilizamos ese término. *[recuperado de [Why Open Source Misses the Point of Free Software](https://www.gnu.org/philosophy/open-source-misses-the-point.html)]*

## Resumen

El **software libre** habla de libertad.  
El **open source** habla de metodología de desarrollo.
