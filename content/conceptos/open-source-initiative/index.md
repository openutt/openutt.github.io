La **Open Source Initiative** (_OSI_) es una organización pública de California, la cual son los encargados de definir _¿qué es el Open Source?_

Sientan las bases para el ecosistema de software de código abierto.
## Filosofía de OSI
### Visión

Como voz líder en las políticas y principios del código abierto, la OSI ayuda a construir un mundo donde todos puedan disfrutar de las libertades y oportunidades del software de código abierto. La OSI apoya a instituciones e individuos que trabajan juntos para crear comunidades de práctica en las que prospere el ecosistema saludable de código abierto.

### Misión

La Iniciativa de Código Abierto (OSI) es una corporación sin fines de lucro con alcance global formada para educar y defender los beneficios del código abierto y construir puentes entre diferentes grupos de interés en la comunidad de código abierto.

El código abierto permite un método de desarrollo de software que aprovecha el poder de la revisión distribuida por pares y la transparencia del proceso. La promesa del código abierto es mayor calidad, mejor confiabilidad, mayor flexibilidad, menor costo y el fin del bloqueo depredador de proveedores.

Una de nuestras actividades más importantes es, como organismo de normalización, mantener [la definición de código abierto](http://www.opensource.org/docs/osd) para el bien de la comunidad. La marca registrada y el programa de Licencia Aprobada de la Iniciativa de Código Abierto crean un nexo de confianza en torno al cual los desarrolladores, usuarios, corporaciones y gobiernos pueden organizar la cooperación en materia de código abierto.
